Arithmetic Progression Lab

📚 Concept Definition

An Arithmetic Progression (AP)A sequence where the difference between consecutive terms is constant. is a sequence of numbers in which the difference of any two successive members is a constant, known as the Common Difference (d).

Graphically, an AP always plots as a set of discrete, collinear points forming a straight line. The slope of this line equals d.

🧮 Core Formulas

an = a + (n − 1)d
Sn = n 2 [ 2a + (n − 1)d ]

💡 Interesting Fact

  • If d > 0, the line goes upwards (Increasing AP).
  • If d < 0, the line goes downwards (Decreasing AP).
  • If d = 0, the line is perfectly horizontal.
  • The area under the plotted discrete bars approximates the sum Sn.

Parameters

First Term (a)The starting value of the sequence. 2
Common Diff. (d)The constant added to each term to get the next. Represents the slope. 3
Number of Terms (n)How many terms to plot. (Discrete domain on X-axis) 10
