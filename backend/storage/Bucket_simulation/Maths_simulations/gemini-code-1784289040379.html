Distance Formula

Coordinate Geometry Laboratory

📐 Definition

The distance formula calculates the shortest straight-line distance between any two distinct points in a Cartesian coordinate system.

💡 How it works

It is a direct application of the Pythagorean Theorem (a² + b² = c²). By creating a right-angled triangle between the two points, the distance becomes the hypotenuse.

📝 Formulas

Given Point A (x₁, y₁) and Point B (x₂, y₂):

d = √(x₂ - x₁)² + (y₂ - y₁)²
Science Fact: This formula calculates Euclidean distance, which assumes a flat 2D space. On the surface of the Earth (a sphere), navigation systems use the Haversine formula instead!
