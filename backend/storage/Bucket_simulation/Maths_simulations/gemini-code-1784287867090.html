Concept Definition

An exponent (or power) refers to the number of times a number (the base) is multiplied by itself.


The general form is a × bx, where:

  • a = Initial Value
  • b = Base (Multiplier)
  • x = Exponent (Steps/Time)

Core Formulas

bm × bn = bm + n
(bm)n = bm × n
b-n =
1 bn

Interesting Fact

🚀

If you were to fold a standard piece of paper in half 42 times, its thickness would reach the Moon! This perfectly illustrates how rapidly values scale when using exponents.
