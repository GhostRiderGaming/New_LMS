Linear Equations Laboratory

📖 Concept

A linear equation in two variables represents a straight line on a Cartesian plane.

A system of two linear equations determines the relationship between two lines. They can intersect at a single point, run completely parallel, or overlap entirely.

📐 Standard Form

The standard algebraic representation is:

a1x + b1y + c1 = 0
a2x + b2y + c2 = 0

Where x and y are variables, and a, b, c are real constants.

🔬 Scientific Fact

Linear systems are crucial in computer graphics, economics, and physics! For example, calculating the exact moment two orbital trajectories cross requires solving pairs of linear equations.
