Definition

A quadratic equation is a second-degree polynomial equation. When graphed on a Cartesian plane, it creates a symmetrical U-shaped curve called a Parabola.

f(x) = ax2 + bx + c

The Quadratic Formula

This universal formula calculates the roots (x-intercepts) of the equation, where y = 0.

x =
-b ± √b2 - 4ac

Scientific Fact

Gravity makes projectiles follow a parabolic trajectory. If you throw a ball, the path it traces through the air is perfectly modeled by a quadratic equation!
