The Christmas Light Problem

Old string lights were wired in Series. If one bulb burned out, it broke the circuit path, and the entire string went dark. Modern homes are wired in Parallel, so if one appliance is turned off, the others keep receiving full voltage.

⚡

The Path of Least Resistance

In a Parallel circuit, current splits based on resistance. A path with lower resistance allows more electrons to flow through it. The total resistance of a parallel circuit is actually less than the resistance of its smallest resistor!
