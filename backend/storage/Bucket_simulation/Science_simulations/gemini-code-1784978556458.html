The Blueprint of Matter

A chemical formula is like a recipe. It tells us exactly which elements are in a compound and how many atoms of each element are present.

Atoms combine to reach a stable state, similar to noble gases. They do this by gaining, losing, or sharing electrons. The number of electrons an atom needs to lose or gain is called its Valency.

  • Symbols represent the elements (e.g., Na for Sodium).
  • Subscripts represent the number of atoms (e.g., the 2 in H₂O).

🌍 Real World Applications

  • Medicine: Formulas dictate exact dosages. Altering one atom can change a cure into a poison.
  • Material Science: Designing new batteries requires balancing complex lithium compounds (e.g., LiCoO₂).
  • Environment: Catalytic converters use Platinum (Pt) to break down toxic NO₂ into harmless N₂ and O₂.

⚠️ Common Mistakes

  • Ca₂O₂ → CaO
    Mistake: Forgetting to simplify the ratio. Formulas show the simplest whole-number ratio.
  • AlSO₄3 → Al₂(SO₄)₃
    Mistake: Forgetting brackets around polyatomic ions when there is more than one.
  • mgcl2 → MgCl₂
    Mistake: Incorrect capitalization. The first letter is always uppercase, the second is lowercase.
